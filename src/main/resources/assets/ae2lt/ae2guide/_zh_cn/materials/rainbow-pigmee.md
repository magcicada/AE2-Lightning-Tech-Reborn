# 彩虹猪咪染色

彩虹猪咪可以制作染料，也能给已有物品换色。合成后猪咪会留在原位，物品的名称、附魔和储存内容会保留。

## 单件循环换色

在任意合成栏中放入一只彩虹猪咪与一件可染色物品，每次将一件物品变为下一个颜色。支持背包的 2×2 合成栏。

颜色按 Minecraft 的 16 色顺序循环：

白 → 橙 → 品红 → 淡蓝 → 黄 → 黄绿 → 粉红 → 灰 → 淡灰 → 青 → 紫 → 蓝 → 棕 → 绿 → 红 → 黑 → 白。

无色物品第一次变为白色，例如玻璃、陶瓦、透明线缆和未染色的潜影盒。皮革装备、盾牌及其他不可堆叠的可染色物品也能逐件换色；混合色皮革会从最接近的 Minecraft 颜色继续循环。

## 四件指定颜色

将彩虹猪咪放在工作台中央，查找所需颜色的染料配方，把配方中的四个染料基底换成四件相同物品，即可得到四件对应颜色的物品。位置与现有 16 种染料配方完全一致，不会自动旋转或镜像。

四件物品必须可堆叠且数据一致，包含名称、附魔和其他保存的数据；不可堆叠的物品请使用单件换色。

## 可染色范围

支持原版彩色方块、猪咪彩色板材与台阶、AE2 与过载线缆，以及能按物品 ID 识别到完整 16 色变体的模组物品。

无色版本根据已加载的染色配方识别：同一种物品 **n 件＋对应染料 → 对应颜色物品 n 件**，且输入、输出数量相同。若一种原料能染成多种不同类型的物品，就不会自动选择其中一种。数据包修改配方后会重新识别。

四个染料基底仍按原配方产出四个染料；八块圆石围住彩虹猪咪仍可制作八块[猪咪建材](pigmee-building-materials.md)。
